picamatl

pure-Rust PDF size optimizer — effective-DPI downsampling, fail-safe by contract

Shrink a real 58-page technical report by 73.6% with the accessibility tags intact — without uploading it anywhere.

Picamatl downsamples embedded images to their effective on-page DPI: the resolution an image actually displays at, not a fixed global target. It runs entirely offline, makes zero network requests, preserves the accessibility structure tree and metadata by default, and never returns output larger than its input. Malformed or hostile files come back byte-for-byte unchanged.

Why not the usual options?

Web compressors upload your documents to someone else's server. Picamatl makes zero network calls.
Ghostscript AGPL, a PostScript interpreter with a CVE history, and it strips accessibility trees. Picamatl is pure Rust, MIT/Apache, and keeps them.
Blind DPI tools downsample every image to one global value. Picamatl reads each image's actual placement and only shrinks what's genuinely over-resolved.
GitHub repository crates.io API documentation
