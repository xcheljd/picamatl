# Test fixtures

`sample.pdf` is a fully synthetic, redistributable four-page PDF (no private
content) generated by `tests/generate_fixture.rs`; regenerate it with
`cargo test --test generate_fixture -- --ignored`. Page 1 carries an 800x800
JPEG drawn at ~400 effective DPI (gets downsampled), page 2 a 200x200 JPEG at
~96 DPI (left untouched), page 3 a 400x400 FlateDecode image with PNG
Up-predictor rows at ~400 DPI (downsampled in place), and page 4 a 150x150
FlateDecode image at ~72 DPI (left untouched).

`fonts/NotoSans-Regular.ttf` (Copyright 2022 The Noto Project Authors,
licensed under the SIL Open Font License 1.1 — full text in `fonts/OFL.txt`)
is the real-font fixture for the font-subsetting tests in `src/fonts.rs` and
the dev-only `scripts/verify-fonts.sh` harness. The font is used only to
build test PDFs; it is not distributed with the crate binary.

The `real_file_shrinks_when_present` test in `src/lib.rs` runs against this
fixture **by default** (not opt-in): measured runtime is ~0.1 s in a debug
build, cheap enough to keep in every `cargo test` run. Override the input with
`AMATL_TEST_PDF=/path/to/other.pdf`; `AMATL_TEST_PACK=1` opts into
object-stream packing and `AMATL_TEST_OUT=/path` saves the optimized output.
`scripts/bench-vs-gs.sh` benchmarks amatl against Ghostscript using the same
harness.

`forms/` holds four synthetic one-page AcroForm fixtures for the
`--flatten-forms` tests, generated by `tests/forms_flatten.rs` (regenerate with
`cargo test --test forms_flatten -- --ignored`). Each carries a filled text
field ("Ada Lovelace") with an appearance stream, a checked checkbox with an
on/off appearance dictionary, a two-button radio group with the second button
selected, an empty field, and a `/Link` annotation that flattening must leave
alone. `filled-acroform.pdf` flattens; `filled-acroform-static-xfa.pdf` adds an
XFA packet set whose data the field tree mirrors, so it flattens too;
`dynamic-xfa.pdf` (`/NeedsRendering true`) and `unappearanced-value.pdf` (a
filled field with no `/AP`) are the decline cases. `scripts/forms-verify.py`
renders any two PDFs through Ghostscript and compares them page by page;
`scripts/forms-census.py` reports what form machinery a PDF carries and what it
costs.
